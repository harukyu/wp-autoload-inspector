Read-only database byte-size inspection of autoloaded WordPress options.

== Description ==
Developer preview. Tools > Autoload Inspector reports totals and the largest stored sizes without fetching option values. Names are opt-in. No cleanup, telemetry or automatic scans. A report is not a speed benchmark. Runtime compatibility has not been validated.

== Installation ==
Upload the plugin ZIP from GitHub Releases, activate on a development installation and open Tools > Autoload Inspector. Requires manage_options.
